# Документация движка DariVN 🌸

<p align="center">
  <b>Русский</b> • <a href="../en/README.md"><b>English</b></a>
</p>

Добро пожаловать в официальную техническую документацию по 2D-движку визуальных новелл **DariVN**!

**DariVN** — это современный, легковесный и высокопроизводительный нативный движок визуальных новелл, разработанный на **C++20** и **OpenGL 3.3 Core Profile** с использованием библиотеки **miniaudio**, **GLFW** и **stb**.

Вся логика визуальной новеллы управляется декларативными конфигурационными файлами и сценариями с расширением `.vn`, а также шейдерами на языке GLSL.

---

## 📚 Разделы документации

Документация разбита на тематические модули с взаимными ссылками:

1. [**Написание сценариев (`scenario.md`)**](scenario.md)
   * Синтаксис скриптового языка `.vn`, реплики персонажей и текст рассказчика.
   * Форматирование текста (цвета, шрифты, стили, паузы печатной машинки).
   * Режимы отображения текста: стандартный **ADV** (нижнее окно) и новелла **NVL** (полноэкранный текст).
   * Переменные, математические и логические выражения, условия `if / else`.
   * Интерактивные развилки (`choice:`) с условиями блокировки и скрытия.
   * Управление сценами, переходами фонов (`with fade / dissolve / crossfade`) и метками (`label`, `jump`).
   * Анимации спрайтов (`hop`, `shake`, `flash`) и перемещения (`move`).

2. [**Конфигурация персонажей (`characters.md`)**](characters.md)
   * Создание и структура конфигурационных файлов `assets/characters/<id>.vn`.
   * Определение эмоций (`expr.<name>`) и спрайтов.
   * Масштабирование, слои рендеринга (Z-ordering) и позиционирование на экране (слоты и координаты).
   * Спрайтовые шейдерные эффекты: силуэты, цветовое тонирование (`tint`), сепия.
   * Подключение кастомных GLSL-шейдеров персонажей.

3. [**Шейдеры и спецэффекты (`shaders.md`)**](shaders.md)
   * Архитектура графического конвейера (OpenGL 3.3, Framebuffer, GLSL 330 core).
   * Конфигурация шейдеров в файлах `assets/shaders/<id>.vn`.
   * Как писать собственные фрагментные шейдеры для фона и персонажей (разбор шейдеров `wave`, `glitch`, `art`).
   * Передача uniform-переменных и изменение параметров шейдеров из сценария на лету.
   * Экранные пост-процессинг эффекты: виньетка (`vignette`), размытие (`blur`), сепия (`sepia`), тонирование (`tint`).
   * Шейдерные переходы между сценами (`fade`, `dissolve`, `crossfade`).

4. [**Аудиосистема (`audio.md`)**](audio.md)
   * Многоканальная звуковая архитектура miniaudio: шины `Master`, `BGM`, `SFX`, `Voice`, `Ambient`.
   * Команды сценария: `play/stop music`, `play sound`, `play voice`, `play/stop ambient`.
   * Плавные затухания/нарастания (`fade`), громкость (`volume`), зацикливание (`loop / noloop`).
   * Автоматический кроссфейд фоновой музыки при смене треков.
   * Автоматическое приглушение звука (Audio Ducking) в меню паузы и окне истории диалогов.

5. [**Конфигурация движка (`configuration.md`)**](configuration.md)
   * Главный конфигурационный файл `assets/config.vn`.
   * Настройка окна (разрешение, заголовок, VSync, полноэкранный режим).
   * Параметры шрифта и типографики.
   * Настройки громкости по умолчанию и длительность кроссфейда.
   * Файл пользовательских переопределений `saves/settings.vn`.

6. [**Система локализации (`localization.md`)**](localization.md)
   * Структура файлов локализации `.ini` в папке `assets/locales/`.
   * Использование ключей локализации в сценарии (`@story.key` и `{loc=char.name}`).
   * Динамическое переключение языков в рантайме.

7. [**Сохранения, глобальные переменные и архитектура (`saves_and_architecture.md`)**](saves_and_architecture.md)
   * Формат файлов сохранений (JSON) и генерация скриншотов предпросмотра (PNG).
   * Слоты сохранений и быстрое сохранение (`F5` / `F9`).
   * Глобальные (персистентные) переменные (`$global.*` и `$persistent.*`), сохраняющиеся между всеми прохождениями.
   * Окно истории реплик (Бэклог / Backlog).
   * Архитектура состояний движка (`StateManager`, `GameplayState`, `MainMenuState` и др.).

8. [**Упаковщик ресурсов и VFS (`packer.md`)**](packer.md)
   * Консольная утилита `darivn-packer` для сборки дистрибутива `game.pak`.
   * Сжатие DEFLATE, сквозное шифрование ключом и контроль целостности CRC32.
   * Виртуальная файловая система (VFS) движка и автоматическое монтирование.
   * Режим разработчика (`--dev`) для мгновенного горячего тестирования ассетов с диска.

## 🗺️ Общая архитектура проекта

```text
DariVN/
├── assets/                  # Ресурсы игры
│   ├── audio/              # Музыка (bgm), звуковые эффекты (sfx), эмбиент
│   │   ├── ambient/
│   │   ├── bgm/
│   │   └── sfx/
│   ├── characters/         # Конфигурационные файлы персонажей (.vn)
│   ├── fonts/              # TrueType шрифты (.ttf)
│   ├── locales/            # Файлы локализации (.ini: ru.ini, en.ini, uk.ini)
│   ├── scripts/            # Сценарии глав (.vn)
│   ├── shaders/            # Конфигурации (.vn) и шейдеры GLSL (.vert, .frag)
│   │   └── custom/         # Пользовательские шейдеры
│   ├── textures/           # Фоны (.jpg, .png), спрайты, элементы интерфейса
│   └── config.vn           # Главный конфигурационный файл игры
├── docs/                    # Документация проекта (вы находитесь здесь)
├── saves/                   # Каталог сохранений игрока и persistent.json
├── src/                     # Исходный код C++20
├── tools/                   # Вспомогательные консольные утилиты
│   └── darivn-packer/       # Исходный код утилиты упаковки ассетов
└── CMakeLists.txt          # Скрипт сборки CMake
```

## ⚡ Быстрый старт

1. Настройте параметры игры в [assets/config.vn](configuration.md).
2. Опишите персонажей в [assets/characters/](characters.md).
3. Создайте сценарий в [assets/scripts/](scenario.md).
4. Добавьте кастомные визуальные шейдеры в [assets/shaders/](shaders.md).
5. Соберите релизный архив игры с помощью [darivn-packer](packer.md)!
