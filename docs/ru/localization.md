# Система локализации (`localization.md`)

<p align="center">
  <b>Русский</b> • <a href="../en/localization.md"><b>English</b></a>
</p>

Движок **DariVN** обладает встроенной системой интернационализации (i18n), позволяющей легко переводить новеллу на множество языков без дублирования сценариев.

Тексты хранятся в простых `.ini`-файлах в каталоге `assets/locales/`, а в сценарии и конфигурации персонажей разработчик может ссылаться на ключи локализации.

## Формат файлов локализации (`.ini`)

Файлы локализации используют кодировку **UTF-8** и располагаются в `assets/locales/` (например, `ru.ini`, `en.ini`, `uk.ini`).

Строки задаются в формате `ключ = значение`:

```ini
# assets/locales/ru.ini

# Имена персонажей
char.dari = {color=cyan}Дари{/color}
char.shadow = {color=#9ca3af}Таинственный силуэт{/color}

# Элементы интерфейса
menu.new_game = Новая игра
menu.load = Загрузить
menu.settings = Настройки
menu.exit = Выход

# Сюжетные реплики
story.welcome = Привет! Рада видеть тебя в нашей новелле!
story.features = Мы умеем менять {color=red}ц{/color}{color=yellow}в{/color}{color=green}е{/color}{color=cyan}т{/color} текста и использовать {b}полужирный шрифт{/b}!

# Варианты выбора
choice.roof_chapter2 = Подняться на крышу школы на закате
choice.stay_class = Остаться в тёплом классе
```

*Значения могут содержать любые теги разметки `{b}`, `{i}`, `{color=...}`, `{scale=...}`, `{w=...}`.*

## Использование в сценариях новеллы

### 1. Локализованные реплики диалогов
Вместо захардкоженного текста на одном языке используйте символ `@` перед ключом:

```ini
# Реплика персонажа по ключу:
dari @story.welcome

# Реплика рассказчика:
@story.narration_intro
```

### 2. Локализованные варианты выбора
В блоке `choice:` ключи локализации также поддерживаются напрямую:

```ini
choice:
    @choice.roof_chapter2 -> script "assets/scripts/chapter2.vn"
    @choice.stay_class -> classroom_scene
```

### 3. Имена персонажей
В файле конфигурации персонажа `assets/characters/dari.vn`:
```ini
id = dari
name = @char.dari
```
Когда игрок переключит язык игры на английский или украинский, имя персонажа в диалоговом окне переведётся автоматически!

### 4. Инлайн-подстановки `{loc=...}`
Если вам нужно вставить локализованное слово внутрь предложения, используйте тег `{loc=ключ}`:

```ini
dari "Мы встретили персонажей: {loc=char.dari} и {loc=char.shadow}!"
```

## Подключение языков в `config.vn`

В `assets/config.vn` укажите язык по умолчанию и пути к файлам:

```ini
locale.default = "ru"
locale.ru = "assets/locales/ru.ini"
locale.en = "assets/locales/en.ini"
locale.uk = "assets/locales/uk.ini"
```

Если в каком-то языке ключ отсутствует, движок автоматически возьмёт значение из языка по умолчанию (`locale.default`), предотвращая падение игры или пустые строки.

---

## Смена языка во время игры

* **В Главном меню:** кнопка переключения языка циклически меняет доступные локали.
* **В Меню настроек (`SettingsState`):** интерактивный переключатель языка обновляет весь интерфейс на лету.
* Выбранный язык игрока автоматически сохраняется в `saves/settings.vn` и восстанавливается при следующем запуске.

## Пошаговый пример: Добавление нового языка

Предположим, мы хотим добавить **немецкий язык (`de`)**.

### Шаг 1. Создание файла `assets/locales/de.ini`
Скопируйте `assets/locales/en.ini` в `assets/locales/de.ini` и переведите значения:
```ini
char.dari = {color=cyan}Dari{/color}
menu.new_game = Neues Spiel
menu.load = Laden
menu.settings = Einstellungen
menu.exit = Beenden
story.welcome = Hallo! Willkommen bei DariVN!
```

### Шаг 2. Регистрация в `assets/config.vn`
Добавьте строку в `assets/config.vn`:
```ini
locale.de = "assets/locales/de.ini"
```

Готово! Движок автоматически зарегистрирует немецкий язык в интерфейсе и позволит игроку выбрать его в настройках.
