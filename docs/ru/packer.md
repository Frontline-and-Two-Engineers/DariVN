# Упаковщик ресурсов и VFS (`packer.md`)

<p align="center">
  <b>Русский</b> • <a href="../en/packer.md"><b>English</b></a>
</p>

Движок **DariVN** включает в себя виртуальную файловую систему (**VFS**) и официальную консольную утилиту **`darivn-packer`**. Она позволяет упаковывать все ресурсы игры (сценарии, фоны, спрайты, музыку, шрифты, шейдеры) в компактный защищённый архив `game.pak` со сжатием **DEFLATE**, проверкой целостности **CRC32** и опциональным шифрованием.

## Зачем нужен упаковщик

1. **Единый файл дистрибутива:** Тысячи мелких текстур, аудиофайлов и скриптов упаковываются в один файл `game.pak`. Игроку передаётся только исполняемый бинарник `DariVN` и `game.pak`.
2. **Сжатие данных (DEFLATE / zlib):** Текстовые сценарии `.vn`, шейдеры, локализации и несжатые форматы графики уменьшаются в размере в среднем на 30–70%, экономя место на диске.
3. **Защита ресурсов от спойлеров:** Опциональное шифрование ключом предотвращает преждевременный спойлер сюжета игроками при вскрытии файлов игры.
4. **Контроль целостности (CRC32):** Каждый файл снабжён контрольной суммой для защиты от повреждения при скачивании или модификаций.
5. **Прозрачная загрузка:** Виртуальная файловая система `DariVN::VFS` прозрачно считывает ресурсы из архива напрямую в память без необходимости предварительной распаковки на диск.

## Сборка утилиты `darivn-packer`

Утилита входит в состав CMake-проекта DariVN и собирается вместе с движком:

```bash
# Сборка проекта (включая darivn-packer)
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target darivn-packer
```

Бинарный файл утилиты появится в каталоге:
* **macOS / Linux:** `build/darivn-packer`
* **Windows:** `build/Release/darivn-packer.exe`

## Команды утилиты

Общий синтаксис:
```bash
darivn-packer <команда> [аргументы] [опции]
```

---

### 1. Упаковка директории (`pack`)

Упаковывает папку со всеми ресурсами в архив `.pak`:

```bash
# Базовая упаковка папки assets в game.pak:
./build/darivn-packer pack assets game.pak

# Упаковка со сквозным шифрованием ключом:
./build/darivn-packer pack assets game.pak --key "MySecretVisualNovelKey2026"

# Упаковка без сжатия (только архивация STORE, полезно для уже сжатых OGG/MP3/PNG):
./build/darivn-packer pack assets game.pak --no-compress
```

*Примечание:* если имя упаковываемой папки — `assets`, утилита автоматически сохраняет внутренние пути с префиксом `assets/` (например, `assets/scripts/demo.vn`), благодаря чему все существующие пути в сценариях продолжают работать без единого изменения!

---

### 2. Просмотр содержимого (`list`)

Выводит таблицу всех файлов в архиве, их оригинальный и сжатый размер, метод сжатия и флаг шифрования:

```bash
./build/darivn-packer list game.pak

# Если архив зашифрован ключом:
./build/darivn-packer list game.pak --key "MySecretVisualNovelKey2026"
```

Пример вывода:
```text
Archive: game.pak
Files:   42
--------------------------------------------------------------------------------
Path                                      Orig Size    Comp Size  Method   Enc
--------------------------------------------------------------------------------
assets/config.vn                            1.04 KB       480 B  DEFLATE    NO
assets/scripts/demo.vn                     10.25 KB      3.12 KB  DEFLATE    NO
assets/textures/backgrounds/rooftop.jpg   450.20 KB    448.10 KB  DEFLATE    NO
assets/audio/bgm/theme.mp3                  3.20 MB      3.18 MB  DEFLATE    NO
--------------------------------------------------------------------------------
Total: 18.40 MB -> 15.20 MB
```

---

### 3. Проверка целостности (`verify`)

Считывает все файлы архива, распаковывает их в памяти и сверяет рассчитанную CRC32 с контрольной суммой из оглавления:

```bash
./build/darivn-packer verify game.pak

# Для зашифрованного архива:
./build/darivn-packer verify game.pak --key "MySecretVisualNovelKey2026"
```

Вывод при успешной проверке:
```text
[VERIFY] Verifying 42 files in 'game.pak'...
[VERIFY] OK! All files and CRC32 checksums are valid.
```

---

### 4. Распаковка архива (`unpack`)

Извлекает все файлы из архива в указанную папку:

```bash
# Распаковать game.pak в папку unpacked_assets/
./build/darivn-packer unpack game.pak unpacked_assets/

# С выводом каждого извлечённого файла:
./build/darivn-packer unpack game.pak unpacked_assets/ --verbose

# Для зашифрованного архива:
./build/darivn-packer unpack game.pak unpacked_assets/ --key "MySecretVisualNovelKey2026"
```

## Опции и флаги командной строки

| Флаг | Короткий | Описание |
|---|---|---|
| `--key <строка>` | `-k <строка>` | Ключ шифрования. Шифрует как оглавление архива (TOC), так и содержимое файлов потоковым XOR-шифрованием. |
| `--no-compress` | — | Отключает сжатие DEFLATE (режим `STORE`). Файлы сохраняются в несжатом виде для максимальной скорости чтения. |
| `--prefix <строка>` | — | Принудительно добавляет строковый префикс ко всем путям внутри архива (например, `--prefix assets`). |
| `--verbose` | `-v` | Подробный вывод прогресса обработки каждого файла. |

## Интеграция с игрой и VFS

Виртуальная файловая система `DariVN::VFS` встроена в ядро движка и инициализируется в самом начале работы `main()`.

### Автоматическое монтирование `game.pak`
При запуске игра автоматически ищет архив `game.pak` (или `assets.pak`) в следующих местах:
1. В текущей рабочей директории игры (`./game.pak`).
2. В директории с исполняемым файлом игры.
3. В родительской директории.

Если архив найден, он монтируется, и все подсистемы движка (текстуры `Texture2D`, шрифты `TextRenderer`, аудио `AudioEngine`, скрипты `ScriptParser`, конфиг `Config`, шейдеры `Shader`) начинают считывать файлы напрямую из памяти через VFS.

Если архив не найден, движок выводит уведомление и бесшовно использует физические файлы из папки `assets/` на диске.

---

### Режим разработчика (`--dev`)

Во время разработки неудобно перепаковывать `game.pak` после каждого изменения реплики или текстуры. Для этого предусмотрен **режим разработчика**:

```bash
# Запуск игры в режиме разработчика:
./build/DariVN --dev
# (Синонимы: -d, --developer)
```

**Разница в поведении:**
* **Release-режим (по умолчанию):** VFS сначала ищет файл в смонтированном `game.pak`, а если его там нет — на диске.
* **Developer-режим (`--dev`):** VFS **в первую очередь проверяет файлы на физическом диске**. Это позволяет авторам новеллы налету менять `.vn` сценарии, конфиги и спрайты без пересборки архива!

## Формат архива (`DVNP`)

Архив DariVN оптимизирован для быстрого произвольного доступа (random access) и последовательного считывания:

```text
+-------------------------------------------------------------------+
| Заголовок ArchiveHeader (64 байта):                               |
|   magic: 'D', 'V', 'N', 'P' (0x504E5644)                          |
|   version: uint32 (версия 1)                                      |
|   flags: uint32 (биты: FLAG_ENCRYPTED = 1)                        |
|   fileCount: uint32                                               |
|   tocOffset: uint64 (смещение к оглавлению архива)                |
|   tocCompressedSize: uint64                                       |
|   tocUncompressedSize: uint64                                     |
|   reserved: uint8[24] (зарезервировано для расширений)            |
+-------------------------------------------------------------------+
| Бинарные полезные нагрузки файлов (Payloads 1..N):                |
|   [Сжатые или несжатые байты каждого файла]                       |
+-------------------------------------------------------------------+
| Оглавление архива (Table of Contents - TOC):                      |
|   Для каждой записи:                                              |
|     pathLen: uint16, path: char[pathLen]                          |
|     offset: uint64, compressedSize: uint64, uncompressedSize: ... |
|     crc32: uint32, compression: uint16, flags: uint16             |
|   (Всё оглавление сжато DEFLATE и опционально зашифровано)        |
+-------------------------------------------------------------------+
```

Такое размещение оглавления в конце файла позволяет дописывать файлы потоково и открывать огромные архивы за доли миллисекунды (считывается только заголовок и оглавление TOC).

## Пошаговый сценарий: Подготовка игры к релизу

Когда ваша новелла готова к публикации:

### Шаг 1. Соберите утилиту упаковщика
```bash
cmake --build build --config Release --target darivn-packer
```

### Шаг 2. Упакуйте папку `assets` в архив `game.pak`
```bash
./build/darivn-packer pack assets game.pak
```

### Шаг 3. Проверьте целостность архива
```bash
./build/darivn-packer verify game.pak
```

### Шаг 4. Проверьте запуск игры только с бинарником и архивом
Переместите бинарник `DariVN` и `game.pak` в отдельную чистую папку (без папки `assets/`) и запустите:
```bash
./DariVN
```
Игра мгновенно смонтирует `game.pak` и запустит новеллу со всеми фонами, звуками и персонажами!
