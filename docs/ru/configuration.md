# Конфигурация движка (`configuration.md`)

<p align="center">
  <b>Русский</b> • <a href="../en/configuration.md"><b>English</b></a>
</p>

Движок **DariVN** настраивается без необходимости перекомпиляции исходного кода C++. Все основные параметры игры — от разрешения окна и VSync до стартового сценария, шрифтов и начальных уровней громкости — задаются в файле `assets/config.vn`.

Пользовательские изменения настроек игрока (сделанные в меню игры) сохраняются отдельно в файл `saves/settings.vn` и автоматически имеют приоритет над значениями по умолчанию.

## Структура `assets/config.vn`

Файл использует простой формат пар ключ-значение `ключ = значение`:

```ini
# ==============================================================================
# Конфигурационный файл визуальной новеллы DariVN (config.vn)
# ==============================================================================

window.title = "DariVN - Visual Novel Engine"
window.width = 1280
window.height = 720
window.vsync = true

menu.background = "assets/textures/backgrounds/classroom.jpg"
menu.music = "assets/audio/bgm/menu_theme.mp3"
menu.shader = ""

font.path = "assets/fonts/roboto.ttf"
font.size = 34.0

locale.default = "ru"
locale.ru = "assets/locales/ru.ini"
locale.en = "assets/locales/en.ini"
locale.uk = "assets/locales/uk.ini"

story.start_script = "assets/scripts/demo.vn"
story.text_speed = 0.020

audio.master_volume = 1.0
audio.bgm_volume = 0.8
audio.sfx_volume = 1.0
audio.voice_volume = 1.0
audio.ambient_volume = 0.7
audio.bgm_crossfade = 1.5

ui.click_sound = "assets/audio/sfx/click.wav"
```

## Параметры окна и графики

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `window.title` | `string` | `"DariVN"` | Заголовок окна операционной системы. |
| `window.width` | `int` | `1280` | Ширина виртуального рабочего разрешения окна в пикселях. |
| `window.height` | `int` | `720` | Высота виртуального разрешения окна (соотношение 16:9). |
| `window.vsync` | `bool` | `true` | Включение вертикальной синхронизации кадров (ограничение частоты кадров по герцовке монитора для предотвращения тиринга). |
| `window.fullscreen` | `bool` | `false` | Запуск игры в полноэкранном режиме. |

---

## Настройки главного меню

| Параметр | Тип | Описание |
|---|---|---|
| `menu.background` | `string` | Путь к изображению фона главного меню (`.jpg` или `.png`). |
| `menu.music` | `string` | Путь к фоновому треку, играющему в главном меню игры. |
| `menu.shader` | `string` | Идентификатор кастомного шейдера, накладываемого на фон меню (например, `art` или `wave`). Оставьте пустым `""` для стандартного отображения. |

---

## Шрифты и типографика

| Параметр | Тип | Описание |
|---|---|---|
| `font.path` | `string` | Путь к файлу шрифта формата TrueType (`.ttf`). Шрифт запекается в видеопамять текстурным атласом через `stb_truetype`. |
| `font.size` | `float` | Базовый размер глифов шрифта в пикселях (рекомендуется `32.0` - `36.0`). |

*Шрифт должен содержать глифы кириллицы и латиницы, если новелла разрабатывается на русском или украинском языках.*

---

## Локализация и языки

| Параметр | Тип | Описание |
|---|---|---|
| `locale.default` | `string` | Код языка по умолчанию (например, `"ru"`), используемый в качестве фолбэка. |
| `locale.<код_языка>` | `string` | Путь к файлу перевода `.ini` для указанного языка. |

Пример подключения трёх языков:
```ini
locale.default = "ru"
locale.ru = "assets/locales/ru.ini"
locale.en = "assets/locales/en.ini"
locale.uk = "assets/locales/uk.ini"
```

Подробнее: [Руководство по локализации](localization.md).

## Настройки игрового процесса и сценария

| Параметр | Тип | Описание |
|---|---|---|
| `story.start_script` | `string` | Путь к начальному сценарию `.vn`, который запускается при нажатии кнопки **«Новая игра»**. |
| `story.text_speed` | `float` | Задержка в секундах между выводом каждого символа эффектом печатной машинки (например, `0.020` = 50 символов в секунду). При установке `0.0` текст выводится мгновенно. |
| `gameplay.auto_dim` | `bool` | Автоматически приглушать (затенять) неактивных персонажей, когда говорит другой герой. |

---

## Аудиопараметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `audio.master_volume` | `float` | `1.0` | Общая громкость всех звуков игры (0.0 — 1.0). |
| `audio.bgm_volume` | `float` | `0.8` | Громкость фоновой музыки. |
| `audio.sfx_volume` | `float` | `1.0` | Громкость звуковых эффектов. |
| `audio.voice_volume` | `float` | `1.0` | Громкость озвучки диалогов. |
| `audio.ambient_volume` | `float` | `0.7` | Громкость фонового эмбиента (шум дождя, ветра). |
| `audio.bgm_crossfade` | `float` | `1.5` | Длительность автоматического кроссфейда музыки в секундах. |
| `ui.click_sound` | `string` | `"assets/audio/sfx/click.wav"` | Звуковой эффект клика по элементам интерфейса. |

Подробнее: [Руководство по аудиосистеме](audio.md).

## Пользовательские переопределения (`saves/settings.vn`)

Когда игрок открывает меню **«Настройки» (`SettingsState`)** и меняет громкость, скорость текста, режим экрана или язык, движок:
1. Не трогает исходный файл `assets/config.vn`.
2. Записывает изменения в персональный файл `saves/settings.vn`.
3. При следующем запуске игры сначала считывает `assets/config.vn`, а затем поверх накатывает значения из `saves/settings.vn`.

При нажатии кнопки **«Сброс»** в настройках файл `saves/settings.vn` сбрасывается к исходным значениям.
