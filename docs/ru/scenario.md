# Руководство по написанию сценариев (`.vn`)

<p align="center">
  <b>Русский</b> • <a href="../en/scenario.md"><b>English</b></a>
</p>

Сценарии в **DariVN** пишутся в текстовых файлах с расширением `.vn` (по умолчанию располагаются в каталоге `assets/scripts/`). Язык сценариев разработан специально для создания визуальных новелл: он декларативен, интуитивно понятен и поддерживает мощную систему интерактивных развилок, переменных, математических выражений и управления визуальными эффектами.

## Базовый синтаксис и комментарии

Каждая строка сценария представляет собой либо команду, либо реплику, либо присваивание переменной. Пустые строки игнорируются.

Комментарии начинаются со знака `#` или двойного слэша `//`:

```ini
# Это однострочный комментарий
// Этот комментарий тоже поддерживается
$score = 10 # Комментарий в конце строки
```

## Реплики диалогов и рассказчик

### Реплика персонажа
Чтобы персонаж произнёс реплику, укажите идентификатор персонажа, за которым в кавычках следует текст реплики:

```ini
dari "Привет! Рада познакомиться с тобой."
```

### Текст рассказчика (без спикера)
Если текст в кавычках написан без указания персонажа, он отображается без имени говорящего:

```ini
"За окном медленно падал первый зимний снег..."
"Я сделал глубокий вдох и открыл дверь школы."
```

### Локализованные реплики
Реплики можно задавать непосредственно ключами из файлов локализации (`assets/locales/`):

```ini
dari @story.welcome
@story.intro_narration
```

Подробнее о локализации читайте в [Руководстве по локализации](localization.md).

## Форматирование текста (Rich-Text) и теги

Движок DariVN поддерживает богатое инлайн-форматирование текста с помощью тегов в фигурных скобках `{...}`:

| Тег | Описание | Пример |
|---|---|---|
| `{b}...{/b}` | Полужирный шрифт (Bold) | `{b}Внимание!{/b}` |
| `{i}...{/i}` | Курсивный шрифт (Italic) | `{i}Он подумал про себя...{/i}` |
| `{color=#HEX}...{/color}` | Кастомный цвет текста в HEX | `{color=#38bdf8}Небесно-голубой{/color}` |
| `{color=name}...{/color}` | Именованный цвет (red, green, blue, yellow, orange, gold, cyan, magenta, purple, white, gray) | `{color=gold}Легендарный предмет{/color}` |
| `{scale=X}...{/scale}` или `{size=X}` | Масштаб размера шрифта (множитель) | `{scale=1.3}Громкий крик!{/scale}` |
| `{alpha=X}...{/alpha}` | Прозрачность текста (0.0 — 1.0) | `{alpha=0.5}Еле слышный шёпот...{/alpha}` |
| `{w=секунды}` или `{w}` | **Пауза эффекта печатной машинки** (по умолчанию 0.4 сек) | `"Раз... {w=1.0}два... {w=1.0}три!"` |
| `{$имя_переменной}` | **Интерполяция переменной** прямо в текст | `"Привет, {b}{$player_name}{/b}! Твои очки: {$points}"` |
| `{loc=ключ}` | Подстановка локализованной строки | `"Персонаж: {loc=char.dari}"` |
| `{{` и `}}` | Экранирование фигурных скобок | `{{Это не тег}}` |

### Пример форматированной строки:
```ini
dari "Привет, {color=#22c55e}{b}{$player_name}{/b}{/color}! Мы ждали тебя {w=0.8}целую вечность..."
```

## Режимы диалога: ADV и NVL

DariVN поддерживает два фундаментальных стиля визуальных новелл:

1. **ADV (Adventure)** — классическое диалоговое окно в нижней части экрана с именем спикера.
2. **NVL (Novel)** — полноэкранный режим чтения (как в *«Бесконечном лете»* или классических новеллах Type-Moon). Реплики накапливаются на экране друг под другом.

### Команды переключения режимов:

```ini
# Включение режима новеллы NVL
nvl on
# (Альтернативы: mode nvl, window fullscreen, nvl show)

"Воспоминания нахлынули внезапно..."
"Зима. Обычная, ничем не примечательная зима..."
dari "И тут передо мной появилась Дари!"

# Очистка накопленного текста на экране (новая страница)
nvl clear

"Новая страница воспоминаний..."

# Возврат в стандартный нижний диалоговый режим ADV
nvl off
# (Альтернативы: mode adv, window bottom, window normal)
```

## Переменные и выражения

Переменные в сценарии предваряются символом `$`. Переменные могут хранить числа (целые и с плавающей точкой), строки и булевы значения.

### Присваивание и операции

```ini
# Базовое присваивание
$player_name = "Алексей"
$points = 0
$visited_roof = false

# Арифметические операторы с присваиванием
$points += 10
$points -= 5
$points *= 2
$points /= 2
```

### Поддерживаемые типы данных
* **Числа:** `10`, `-5`, `3.1415`
* **Строки:** `"Привет"`, `'Мир'`
* **Булевы:** `true`, `false`
* **Null:** `null`, `none`, `nil`

### Глобальные (персистентные) переменные
Обычные переменные сохраняются в конкретный слот сохранения игрока. Если вам нужны переменные, **сохраняющиеся глобально между всеми прохождениями и перезапусками игры** (например, счётчик запусков, открытые концовки, галерея артов), используйте префиксы `$global.` или `$persistent.`:

```ini
# Этот счётчик не сбрасывается при начале новой игры!
$global.started_counter += 1
$persistent.true_ending_unlocked = true
```

Персистентные переменные автоматически сохраняются в файл `saves/persistent.json`.

## Условные конструкции (`if / else`)

Вы можете выполнять любые команды сценария условно:

```ini
# Формат: if <условие> then <команда>
if $points >= 50 then dari "Ты отлично справился!"

# Двоеточие в качестве разделителя:
if $visited_roof: scene "assets/textures/backgrounds/rooftop.jpg"

# Прямой переход по условию:
if $points < 10 jump bad_ending_label

# Условие с альтернативным переходом:
if $points >= 100 jump secret_scene else jump common_scene
```

### Логические операторы:
* Сравнение: `==`, `!=`, `<`, `<=`, `>`, `>=`
* Логика: `and`, `or`, `not`
* Скобки: `if ($points > 10 and not $visited_roof) or $global.started_counter > 5 jump bonus_label`

## Фоны и переходы между сценами

### Смена фона
Фон устанавливается командой `scene` (или `bg`). Поддерживаются плавные шейдерные переходы:

```ini
# Мгновенная смена фона
scene "assets/textures/backgrounds/classroom.jpg"

# Смена фона с плавным затемнением (Fade) длительностью 1.5 секунды
scene "assets/textures/backgrounds/classroom.jpg" with fade 1.5

# Плавное перетекание кадров (Crossfade)
scene "assets/textures/backgrounds/rooftop.jpg" with crossfade 2.0

# Шейдерное пиксельное растворение (Dissolve)
scene "assets/textures/backgrounds/rooftop.jpg" with dissolve 1.5
```

### Автономный переход
Вы можете запустить шейдерный переход сцены отдельно:

```ini
transition fade 1.0
transition dissolve 1.5
```

## Отображение и позиционирование персонажей

Перед использованием персонажа его конфигурацию необходимо загрузить:

```ini
load character dari
load character shadow
```
*(Файлы конфигураций загружаются из `assets/characters/<id>.vn`. Подробнее: [Конфигурация персонажей](characters.md))*

### Показ персонажа (`show`)
```ini
# Показ по слоту (left, center, right)
show dari at center

# Показ конкретной эмоции
show dari happy at right

# Явное указание слоя отрисовки (Z-ordering)
show shadow at left layer 0
show dari at center layer 1

# Свободные экранные координаты X Y
show dari at 640 100 layer 1

# Масштабирование персонажа
show dari at center scale 1.2
```

### Перемещение персонажа (`move`)
Плавное перемещение персонажа на новую позицию:

```ini
# Перемещение только по координате X
move dari to 680

# Перемещение в слот
move dari to right

# Перемещение по координатам X и Y
move dari to 300 120
```

### Скрытие персонажа (`hide`)
```ini
hide dari
hide shadow
```

## Процедурные анимации спрайтов

DariVN включает встроенные процедурные микро-анимации, не требующие покадровых текстур:

### 1. Подскок от радости (`hop`)
```ini
# hop <персонаж> [длительность=0.3] [высота=25.0]
hop dari 0.3
dari "Ура! У нас получилось!"
```

### 2. Вздрагивание / испуг (`shake`)
```ini
# shake <персонаж> [длительность=0.4] [интенсивность=15.0]
shake dari 0.4
dari "Ой! Что это за звук?!"
```

### 3. Белая вспышка на спрайте (`flash`)
```ini
# flash <персонаж> [длительность=0.25]
flash dari 0.25
```

## Эффекты спрайтов

Команда `effect <character>` позволяет модифицировать внешний вид спрайта:

```ini
# Цветовое тонирование (холодный ночной оттенок R G B):
effect dari tint 0.6 0.6 0.95

# Превращение персонажа в таинственный теневой силуэт:
effect dari silhouette true

# Отключение силуэта:
effect dari silhouette false

# Индивидуальная сепия персонажа (от 0.0 до 1.0):
effect dari sepia 1.0

# Сброс всех эффектов персонажа к обычным:
effect dari clear
```

## Интерактивные выборы (`choice:`)

Блок выбора развилки начинается со строки `choice:`. Варианты указываются с отступом и завершаются стрелкой `->` и меткой перехода:

```ini
choice:
    "Пойти на крышу школы" -> rooftop_scene
    "Остаться в классе" -> classroom_scene
```

### Условия доступности вариантов
Вы можете добавлять условия `if <условие>` к каждому варианту:

```ini
choice:
    # Вариант скроется, если условие не выполнено
    "Осмотреть крышу" if not $visited_roof -> rooftop_scene
    
    # Вариант отобразится серым и заблокированным (Disabled/Locked)
    "Взломать сейф" if $points >= 100 else disable -> safe_scene
    
    # Альтернативный синтаксис блокировки:
    "Секретная комната" if $has_key [lock] -> secret_room
```

### Переход в другой файл сценария из развилки
Вариант выбора может сразу перенаправлять в другой файл сценария:

```ini
choice:
    "Начать главу 2" -> script "assets/scripts/chapter2.vn"
    "Секретный пролог" -> script "assets/scripts/prologue.vn" secret_label
```

## Метки и переходы (`label`, `jump`)

Метки организуют структуру сюжета и нелинейные ветвления:

```ini
label rooftop_scene
$visited_roof = true
scene "assets/textures/backgrounds/rooftop.jpg" with fade 1.0
dari "Как здесь красиво!"
jump common_ending

label classroom_scene
dari "В классе тоже уютно."
jump common_ending

label common_ending
dari "Спасибо за игру!"
```

### Переход в другой файл сценария
```ini
# Переход в начало другого сценария:
jump script "assets/scripts/chapter2.vn"

# Переход на конкретную метку в другом сценарии:
jump script "assets/scripts/chapter2.vn" rooftop_scene
```

## Управление звуком и музыкой

```ini
# Фоновая музыка с зацикливанием, плавным появлением и громкостью
play music "assets/audio/bgm/theme.mp3" loop fade 1.5 volume 0.8
stop music fade 2.0

# Звуковые эффекты (SFX)
play sound "assets/audio/sfx/bell.wav"

# Озвучка диалога (Voice)
play voice "assets/audio/voice/line_001.mp3"

# Фоновый эмбиент (шум ветра, дождь)
play ambient "assets/audio/ambient/wind.mp3" loop fade 2.0 volume 0.7
stop ambient fade 1.5
```

Подробнее: [Руководство по аудиосистеме](audio.md).

## Применение шейдеров

### Экранные пост-эффекты:
```ini
effect vignette 0.8  # Кинематографичная виньетка
effect sepia 1.0     # Тёплый ретро-фильтр воспоминаний
effect blur 0.6      # Мягкое размытие (обморок, сон)
effect clear         # Сброс всех экранных пост-эффектов
```

### Пользовательские GLSL шейдеры:
```ini
# Загрузка конфигураций шейдеров
load shader wave
load shader glitch

# Применение шейдера волн к фону:
shader scene wave
shader scene set u_Speed 4.0
shader scene clear

# Применение глитча к спрайту персонажа:
shader dari glitch
shader dari clear
```

Подробнее: [Руководство по шейдерам](shaders.md).
